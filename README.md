## About Me

I’m an AI Engineer focused on building systems that are actually useful outside notebooks.

Right now, I’m exploring:

- Graph-based recommendation systems
- AI agents & multi-agent workflows
- Retrieval-Augmented Generation (RAG)
- NLP & LLM fine-tuning
- Production-ready ML systems
- MLOps & scalable inference pipelines

I care a lot about:

- System design
- Reliability
- Evaluation
- Scalability
- Building things people would genuinely use

Most of my work starts from a simple question:

> “How would this behave in the real world?”
